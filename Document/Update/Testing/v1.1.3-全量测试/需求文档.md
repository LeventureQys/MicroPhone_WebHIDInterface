## 1. 背景与目标

麦克风上位机 MIC STUDIO（Electron 33 + WebHID，`package.json` version `1.1.2`）已完成界面层（Alpha v1.0.0）与参数协议 / 固件升级链路（Alpha v1.1.0），并在 2026-11-21 落地了参数表 V0.3（`Document/Update/hardware/v0.0.6/修复记录-参数表V0.3-20261121.md`）。此前的验证都是**按功能点增量取证**（单测 + 定向探针），缺少一次**跨全模块、可复现、有统一门禁口径**的验收。

本轮目标：

1. 对当前代码基线做一次**全量测试**：静态门禁 → 单元测试与覆盖率 → 虚拟下位机端到端 → 构建 → 打包 → 启动冒烟 → 界面全量功能走查 → 真机 M001 联调 → 稳定性与回归。
2. 产出一份**可复核的测试证据包**（命令、退出码、截图、日志、原始数据）和一份**缺陷清单**。
3. 允许直接修复缺陷并复测，最终给出「通过 / 不通过」结论与遗留项。
4. 在阶段四之后再追加一轮**深度冒烟 + ≥2 小时耐久测试**（§5.7）：用交付的 portable 产物走完整用户旅程，并并行跑真机与 mock 两路 135 分钟耐久；结果并入 `验收报告.md`，不单列报告。

**非目标**：新增功能、重构、UI 改版、固件改动、DFU 实刷（见 §3.2）。
