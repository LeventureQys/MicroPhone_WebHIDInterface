## 5. 失败与阻塞处理

| 情况 | 处理 |
|---|---|
| 单个验收项失败 | 记 `失败`，写清失败现象 + 期望 + 实际 + 证据路径；**不阻断**其它项 |
| 前置条件（P1–P5）失败 | 整轮记 `阻塞`，列出阻塞项与解除条件；本轮不出"通过"结论 |
| B 组无麦克风 | B4/B6、F3 记 `阻塞`（注明"本机无可用输入设备"），其余照跑 |
| llama-server 起不来 | D4/D5/G1 记 `阻塞`；其余可跑（规则层路径独立） |
| 连续 3 次同一项失败 | 停止该项，把根因写进验收报告，并升级到问题清单的置顶区（v3） |
| 发现设计文档与实现冲突 | 以设计文档为准；记 `失败` 并注明"实现偏离契约 §X" |
