# 设计文档 - Alpha v1.0.0

麦克风上位机（Electron + WebHID 方向）Alpha 版界面。本文档为零上下文文档：读者不需要任何对话历史即可照此实现。

## 1. 背景与目标

产品是面向 toC 商业客户的麦克风上位机软件：显示下位机实时电平与参数状态，可调参数实时写回下位机。通信走 HID 协议。

Alpha v1.0.0 只交付**界面层**：不联调真实设备，全部设备数据由 Mock 数据源提供；但通信层接口必须先定死，后续接入只补实现、不改 UI。

交付形态：可双击运行的 Electron 桌面应用（Windows 产物本轮验证，macOS/Linux 只保证代码与构建配置跨平台）。

## 2. 需求映射

| 需求 | 落地 |
|---|---|
| 显示下位机实时电平 | 电平页双通道电平表，Mock 数据源 60fps 驱动，含峰值保持 |
| 显示下位机参数 | 参数面板回显当前值；Gain.Mic / Gain.Hp 为只读显示 |
| 调整参数并实时写入 | 所有可调控件改动即推送 `Transport.write()`；Mock 阶段记录写入缓冲并在顶栏显示同步状态 |
| HID 协议 | `Transport` 接口 + `HidProtocol` 帧占位；`WebHidTransport` 只留骨架 |
| 参数范围约束 | 全量参数范围/默认/步进/读写权限来自 `Document/Protocol/效果器参数范围.xlsx`，见 §5.1 |
| 中文 + 英文双语 | 自建 i18n 字典，顶栏切换，持久化 |
| EQ 曲线 | 14 段建模，7 段上位机可调；Canvas 分层渲染，对数频率轴 |

**版本冻结**：`electron@33.4.11`、`electron-vite@5.0.0`、`vite@5.4.21`、`vitest@1.6.1`、`happy-dom@20.14.6`、`electron-builder@26.15.3`。不升级，避免引入未验证的兼容问题。

已实测的构建事实（本仓骨架已按此落盘并通过构建/类型检查/启动验证）：

- `package.json` **不得**带 `"type": "module"`：一旦带，preload 产物变成 `index.mjs` 而主进程按 `index.js` 引用，运行时报 `Unable to load preload script`。
- 三端配置**不写 `build.outDir`**：electron-vite 固定输出 `out/main`、`out/preload`、`out/renderer`；写 `outDir`/`rollupOptions` 会撞上 electron-vite 5 与 vite 5 的类型不匹配。
- `electron.vite.config.ts` 不纳入 `tsconfig.json` 的 `include`，配置正确性由 `pnpm run build` 保证。
- `pnpm-workspace.yaml` 必须放行 electron/esbuild 的构建脚本（`allowBuilds`），否则 pnpm 11 会让 `pnpm run *` 连锁失败。

## 5. 契约

### 5.1 参数规格（`src/renderer/src/domain/params.ts`）

唯一真值源。任何模块不得就地重写字面量范围。

```ts
export type ModuleId = 'gain' | 'noisegate' | 'comp' | 'limit' | 'eq' | 'enc' | 'drc3';

export interface ParamSpec {
  /** 形如 'noisegate.threshold_db'，全局唯一 */
  id: string;
  module: ModuleId;
  /** 协议字段名，原样展示，不翻译成语义标签 */
  field: string;
  /** 数值单位，'' 表示无量纲 */
  unit: 'dB' | 'Hz' | 'ms' | 's' | '';
  min: number;
  max: number;
  step: number;
  default: number;
  /** true = 只读展示，不提供控件 */
  readonly: boolean;
}

export const PARAMS: readonly ParamSpec[];
export function findParam(id: string): ParamSpec | undefined;
export function paramsOf(module: ModuleId): readonly ParamSpec[];
```

`PARAMS` 共 **36 项**（Gain 2 + NoiseGate 6 + Comp 6 + Limit 3 + ENC 2 + 3BandDrc 17），数值见 `AGENTS.md` 的「模块与参数字段」表与 `SubStage_2.1.md` §3.1 的完整清单，一一对应，一个不少一个不多。字段名沿用协议原样：`Mic`、`Hp`、`threshold_db`、`ratio`、`attack_ms`、`release_ms`、`knee_width_db`、`hp_freq`、`MakeUpGain`、`Threshold`、`Attack`、`Release`、`Rate`、`KneeWidth`、`OnOff`、`Level`、`fc1`、`fc2`、`preGain`、`threshold`、`attackTime`、`releaseTime`、`ratio`。

3BandDrc 的 15 个区域参数 id 规则：`drc3.<band>.<field>`，其中 `<band>` ∈ `low`（freq < fc1）、`mid`（fc1..fc2）、`high`（freq > fc2），`<field>` ∈ `preGain|threshold|attackTime|releaseTime|ratio`。分频点 id 为 `drc3.fc1`、`drc3.fc2`。
EQ 段参数不进 `PARAMS`（走 `EqModel`，见 §5.3）。

### 5.2 数值规则（`src/renderer/src/domain/values.ts`）

```ts
export function clampValue(spec: ParamSpec, raw: number): number;      // 非法（NaN/±Inf）返回 spec.default
export function quantize(spec: ParamSpec, value: number): number;      // round((v-min)/step)*step+min，再 clamp
export function formatValue(spec: ParamSpec, value: number): string;   // 量化后取最短表示：0.1 → "0.1"，0.0005 → "0.0005"，6 → "6"
export function parseInput(spec: ParamSpec, text: string): number | null; // 空/非数 → null，调用方保留旧值
```

错误处理：上述函数**不抛异常**。`parseInput` 返回 `null` 时 UI 回填上一次有效值。

### 5.3 EQ 模型（`src/renderer/src/eq/model.ts`）

```ts
export type EqFilterType = 0 | 1 | 2 | 3 | 4;  // 0 PEAK, 1 LS, 2 HS, 3 LPF, 4 HPF

export interface EqBand {
  index: number;        // 0..13
  type: EqFilterType;
  freq: number;         // 20..20000 Hz
  gain: number;         // -32..12 dB
  q: number;            // 0.1..12
}

export class EqModel extends EventTarget {
  constructor(bands?: EqBand[]);           // 缺省用 defaults.ts 的 14 段
  bandAt(index: number): EqBand | undefined;   // 返回副本
  allBands(): readonly EqBand[];               // 副本，按 index 升序
  setBand(index: number, patch: Partial<Pick<EqBand,'type'|'freq'|'gain'|'q'>>): void; // 内部 clamp + quantize(step: freq 1, gain 0.1, q 0.1, type 1)，越界 index 静默忽略，变化后派发 'band-changed'
  resetBandGain(index: number): void;      // gain→0，q→0.7
  focusedIndex(): number;
  setFocused(index: number): void;         // -1 表示无聚焦，派发 'focus-changed'
  visibleCount(): number;                  // 固定 7：上位机可调段数
}
```

事件 detail：`{ index: number, band: EqBand }`。`EqModel` 不允许增删段（Alpha 固定 14 段）。

### 5.4 频响与采样（`src/renderer/src/eq/curve.ts`）

```ts
export interface CurvePoint { freq: number; gainDb: number }
export function computeCurve(bands: readonly EqBand[], opts?: {
  sampleRate?: number;     // 默认 48000
  pointCount?: number;     // 默认 480
  freqMin?: number;        // 默认 20
  freqMax?: number;        // 默认 20000
}): CurvePoint[];
```

算法：RBJ biquad（PEAK / low shelf / high shelf）+ BLT Butterworth（LPF / HPF，Q 由段自身提供），在频域求模后取 20log10 叠加。数学实现参照 MIT 许可的 `AudioEQ_Visualized_Web`（`src/core/filter/ButterworthIIR.js`），移植时在文件头保留版权说明。频率点按对数等距生成。任何一段的 `freq` 需 clamp 到 `[20, min(20000, sampleRate/2*0.999)]`，避免数值爆掉。

契约：`computeCurve` 对 14 段全量求和；`gain === 0 && type === 0` 的段贡献恒为 0（可用于跳过计算）。

### 5.6 传输层（`src/renderer/src/device/transport.ts`）

```ts
export type TransportState = 'idle' | 'connecting' | 'ready' | 'error';

export interface LevelFrame {
  /** 毫秒时间戳 */
  t: number;
  /** 输入 RMS，dBFS，-96..0 */
  inputRms: number;
  inputPeak: number;
  outputRms: number;
  outputPeak: number;
}

export interface ParamWrite { id: string; value: number }

export interface Transport {
  readonly kind: 'mock' | 'webhid';
  state(): TransportState;
  open(): Promise<void>;                       // 失败 → state 'error'，不抛给调用方
  close(): Promise<void>;
  write(updates: readonly ParamWrite[]): void; // 同步返回，不抛；内部失败经 onStateChange 报告
  onLevels(cb: (frame: LevelFrame) => void): () => void;      // 返回取消订阅函数
  onStateChange(cb: (state: TransportState) => void): () => void;
}
```

`MockTransport` 附加（仅测试与开发使用，不在 `Transport` 接口内）：

```ts
export class MockTransport implements Transport {
  constructor(options?: { hz?: number; scene?: MockScene });
  setScene(scene: MockScene): void;          // 'silence' | 'speech' | 'music'
  writtenBuffer(): readonly ParamWrite[];    // 累计写入记录，用于单测与调试
  lastFrame(): LevelFrame | null;
}
export type MockScene = 'silence' | 'speech' | 'music';
```

行为：`open()` 后 20ms 间隔（50Hz）产帧；`silence` 底噪 -72±1 dBFS；`speech` 激活段 0.6–3s、峰值 -14..-3 dBFS、静默段 -68 dBFS；`music` 持续波动 -22..-6 dBFS。输出电平 = 输入 - 3dB 常数差。写入通过 `write()` 追加进缓冲，不产生回包。

`WebHidTransport`（`webhid-transport.ts`）：只声明类与 `TODO`，`open()` 直接 `throw new Error('webhid transport not implemented in alpha')` 由调用方捕获转为 state 'error'。**不实现字节编解码。**

`protocol.ts`：定义 `HID_REPORT_ID = 0`、`MAX_PAYLOAD = 64` 常量与 `interface HidFrame { reportId: number; payload: Uint8Array }`，并注释说明"参数→字节的映射待 HID 报告描述符确认"，不写编码函数。

### 5.7 应用状态（`src/renderer/src/domain/state.ts`）

```ts
export interface AppState {
  lang: 'zh' | 'en';
  module: ModuleId | 'meter' | 'settings';   // 当前路由
  params: Readonly<Record<string, number>>;  // 全部 36 个标量的当前值
  bands: readonly EqBand[];                  // 14 段
  focusedBand: number;                       // -1..6
  transport: TransportState;
  scene: MockScene;
}

export class AppStore extends EventTarget {
  constructor(transport: Transport, initial?: Partial<AppState>);
  get(): AppState;
  setParam(id: string, value: number): void;   // 校验 + 量化，变化后派发 'param-changed' {id, value} 并调用 transport.write([{id,value}])
  setBands(bands: readonly EqBand[]): void;
  setFocus(index: number): void;
  setModule(m: AppState['module']): void;
  setLang(lang: 'zh' | 'en'): void;            // 同时写 localStorage
  setScene(scene: MockScene): void;            // 转发给 MockTransport
  subscribe(ev: 'change', cb: (s: AppState) => void): () => void;
  /** 便捷订阅（内部同样走 'change'） */
  onChange(cb: (s: AppState) => void): () => void;
}
```

规则：`setParam` 对只读参数直接返回（不写入、不派发）。数值无变化时不派发事件、不写设备。

### 5.10 主进程（`src/main/index.ts`）

- 启动前覆盖 userData（本机沙箱环境必需，见 `AGENTS.md` 已知坑 6）：
  ```ts
  const userDataOverride = process.env.MICSTUDIO_USER_DATA
    ?? (app.isPackaged ? '' : path.join(process.cwd(), '.userdata'));
  if (userDataOverride) app.setPath('userData', userDataOverride);
  ```
  开发态落项目内 `.userdata`（不要用 `os.tmpdir()`，本机临时目录下 Chromium 缓存目录会因权限被拒而刷错误日志）；打包产物由 `MICSTUDIO_USER_DATA` 指定；用户真机不设环境变量时使用 Electron 默认目录。
- 窗口：`1280×820`，`minWidth 1100`，`minHeight 700`，`backgroundColor '#0e1118'`，`autoHideMenuBar: true`，`show: false` 待 `ready-to-show` 再显示（防白闪）。
- `webPreferences: { preload, contextIsolation: true, nodeIntegration: false, sandbox: true }`。
- 生产加载 `out/renderer/index.html`；dev 加载 `process.env.ELECTRON_RENDERER_URL`。
- `--screenshot=<file>` 启动参数：窗口加载完成后等 1200ms，`webContents.capturePage()` 写 PNG，打印 `[screenshot] <path>` 后 `app.quit()`，退出码 0。供验收取证。
- `single instance` lock：第二实例直接聚焦已有窗口。
- WebHID：`app.on('session-created')` 里挂 `session.setDevicePermissionHandler`（HID 白名单放行）与 `session.on('select-hid-device')` 处理，Alpha 阶段允许但不主动触发。

### 5.12 界面结构

顶栏（左→右）：品牌标记 + `MIC STUDIO` / 副标；连接状态 pill（未连接 / 模拟中 / 已连接 / 错误）；语言切换（中/EN 分段）；「连接设备」按钮。

左导轨 6 项：电平、输入、EQ、动态、分频、设置。当前项高亮（左侧 2px 强调条 + 强调色图标）。

- **电平页**：左侧双通道电平表（输入/输出，垂直柱，-60..0 dBFS，峰值保持刻度，数值显示 RMS 与 Peak）；右侧三张卡：增益（Mic/Hp 只读）、场景模拟（静音/说话/音乐 分段按钮）、状态（Transport 状态 + 已写入次数）。
- **输入页**：增益只读卡 + NoiseGate 六参数卡（滑块 + 数字输入）+ ENC 卡（开关 + 档位分段 0–3）。
- **EQ 页**：主区曲线工作台（工具条：段数徽标、频率范围说明、重置全部）+ 右侧段列表（7 行，列：编号/类型下拉/频率/增益/Q），底部折叠区「内部调音段 7–13（只读）」。
- **动态页**：Comp 六参数 + Limit 三参数，两张卡。
- **分频页**：fc1/fc2 两个滑块 + 三张区域卡（低/中/高，每张 5 参数），卡头标注区间条件。
- **设置页**：语言、模拟场景、恢复默认参数、关于（版本/平台/协议占位说明）。

响应式：≥1050px 保持「导轨 + 内容」；<1050px 内容单列，面板卡两列变一列；<680px 仅保证不破版（不做移动端专门交互）。

## 8. 边界与未验证项（必须如实带入验收）

1. macOS（dmg）与 Linux（AppImage）产物本轮**不做验证**：无对应环境。只保证源码无平台分支、`electron-builder.yml` 配置齐全。
2. 真实 HID 联调不在本轮范围：`WebHidTransport` 只有骨架，`HidProtocol` 只有常量与占位类型。
3. 应用图标暂用 electron-builder 默认图标（无品牌资产）；`electron-builder.yml` 预留 `icon` 字段。
4. 安装包未做代码签名与公证；Windows SmartScreen 可能提示未知发布者。
5. 本机 Electron 启动需 `MICSTUDIO_USER_DATA` 覆盖 userData（沙箱环境限制，非产品缺陷）。

## 9. 禁止事项

- 不得在渲染进程使用 Node/Electron API（`fs`、`path`、`ipcRenderer` 直连）；一律经 preload 暴露的 `window.micstudio`。
- 不得引入 UI 框架、状态库、CSS 框架、i18n 库、图表库。依赖白名单：`electron`、`electron-vite`、`vite`、`typescript`、`vitest`、`happy-dom`、`electron-builder`。
- 不得引用网络字体或 CDN 资源（离线必须可用）。
- 不得在参数面板里重写 min/max/step 字面量，必须读 `PARAMS`。
- 不得为 `Comp.Rate`、`NoiseGate.ratio` 编造中文语义标签。
- 不得修改 `Document/Protocol/效果器参数范围.xlsx` 与 `Document/Update/Alpha/v1.0.0/需求文档.md`。
- 不得跨 SubStage 修改他人文件；缺口上报主 Agent。
