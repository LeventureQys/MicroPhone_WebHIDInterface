# 需求文档

简单说明一下，当前这个项目主要是作为一个麦克风的上位机软件，主要是商业客户，也就是toC的产品

当前为alpha v1.0.0阶段，主要只涉及UI前端界面的设计，暂时不需要进行数据的联调。

当前的软件最具体的作用主要是

1. 显示下位机的数据，比如电平的实时数据，以及下位机的电平等参数。

2. 调整下位机参数，上位机调节需要可以提供给下位机实时写入

3. 设备之间使用的是HID协议，当前aplha v1.0.0阶段主要仅涉及UI前端界面的设计。

4. EQ曲线的设计请你参考https://github.com/LeventureQys/AudioEQ_Visualized_Web 这个项目，你可以自由拉取这个项目，并且你可以以这个项目的设计和审美作为你的思路来进行软件界面的设计。

5. 你可以调节的和你需要检查的参数在Document\Protocol\效果器参数范围.xlsx 下面，请你开始工作吧。
