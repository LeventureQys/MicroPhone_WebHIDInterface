## 2. 怎么用

1. 把 exe 拷到目标机（Windows 10/11 x64），双击即可，不需要安装 Node.js 或任何运行库。
2. 插着 M001（`VID 0A67 / PID 0010`）时启动后自动连接、自动同步参数，顶栏显示「已连接 / 已同步」。
3. 配置与启动日志写在 **exe 同级的 `MicStudioData\`**（便携模式，不写系统 AppData）；
   出问题先看 `MicStudioData\startup.log`。
4. 没有真机时可在设备抽屉里用虚拟桥接通道演示（需另起 `pnpm run vdevice`，不随包分发）。

## 5. 交付注意 / 已知限制

1. **未签名**：目标机首次运行会弹 SmartScreen，点「更多信息」→「仍要运行」；被安全软件隔离需加信任。
2. **本机（开发机）策略**：开启了 Smart App Control / WDAC，未签名 exe 直接双击会被拦（退出码 `0x80000003`，不写 `MicStudioData`），
   验证时要用 `cmd /c start "" "<exe 完整路径>" --no-sandbox`；这与产物本身无关，目标机是否同样需要取决于那台机器的策略。
   纯双击测试在本机会卡在 SmartScreen 弹窗上，自动化里不要用 `Start-Process` 无参直接拉。
3. **三分频听感**：第六轮联调发现固件预设结构体从 `0x205B` 起整体右移 2 字，上位机侧只能保证可写可回读；
   「调了听不出变化」需固件确认 DSP 取值偏移，不是本包能修的。
4. **拔插自愈三条待现场复测**：真机拔插、关麦克风权限、换 USB 口（端点 id 变化），口径见
   `修复记录-音频电平自愈-20261114.md` §6。
5. **源码未提交**：本包由工作树（`caa138f` + 未提交改动）构建。若要可追溯的交付，先提交工作树里的改动再跑
   `.\dist.cmd`，产物 SHA256 会随之变化；对外分发请以 `release/build-info.txt` 里的 SHA256 为准。
