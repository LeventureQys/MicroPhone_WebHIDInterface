## 2. 怎么用（给客户）

1. 把 `MicStudio-1.1.3-portable.exe` 拷到目标机（Windows 10/11 x64），**双击即可**，不需要安装任何东西。
2. 若双击一闪而过（本机策略限制 Chromium 沙箱），改用同目录的 **`MIC STUDIO.exe`**（一键启动器）或
   `cmd /c start "" "<exe 完整路径>" --no-sandbox`。
3. 插着 M001（`VID 0A67 / PID 0010`）时启动后自动连接、自动同步参数，顶栏显示「已连接 / 已同步」。
4. 配置与启动日志在 **exe 同级的 `MicStudioData\`**（便携模式，不写系统 AppData）；出问题先看 `MicStudioData\startup.log`。
5. 没有真机时界面显示「演示数据」，可直接看交互；虚拟桥接通道需要另起 `pnpm run vdevice`，不随包分发。

## 3. 相对 1.1.2 的变化（全部在上位机界面层，不改协议与参数表）

| # | 问题单条目 | 本版行为 |
|---|---|---|
| 1 | 耳机增益 → 耳机音量 | 主界面读数与高级参数标签都改成「耳机音量」（英 Headphone volume） |
| 3 | 噪声门 / 压缩器要开关并联动 | 「快速调音」里 `噪声门阈值 / 压缩器阈值` 两行各带一个开关，写的就是高级参数里同一个 `0x2074` / `0x204A`，两处任改一处都同步 |
| 4 | 限幅器阈值进快速调音 | 新增第三行 **`防爆音`**（主界面沿用产品叫法，高级参数里仍叫「限幅器」）+ 阈值 + 开关（`limit.Enable`）；「快捷开关」里原来的「防爆音」开关**移除**（一个模块只留一个开关）。第一次打包曾把这一行叫「限幅器阈值」，用户反馈"界面上的防爆音没了"，已改回 |
| 5 | 逐段精调要跳均衡器页 | 点「逐段精调」后抽屉直接滚到「均衡」一节，跳转条同步高亮 |
| 6 | 三个输入开关不在同一水平线 | 修掉三列网格里多出来的 10 px 行间距，三个开关 top 完全一致 |
| 9 | 删掉 `0x352F` | 设置 → 通道 → VID / PID 列表的占位符改成 `0x0A67`，整页不再出现该字符串 |
| 10 | 输出峰值不要 | 电平表输出通道只画 RMS 与 LED 段（峰值读数与保持线都不画），输入通道保留 |
| 12 | 均衡器复位按图参数 | 复位后 7 段增益 **0 dB**、Q **0.7**，类型/频点沿用参数表（HPF 50 / LPF 20000 / PEAK 215·1000·2000·5000·10000）；新增 `domain/eq-reset.ts`，与高级参数「全部复位」共用 |
| 13 | 复位按钮放音色曲线卡 | 曲线卡头并排「复位」「逐段精调」；只有选中「自定义」音色时「复位」可用 |
| 11 | 噪声门压缩比 | 标签「扩展比」→「压缩比」（`0x205C`），噪声门卡加一行用法说明：开关 + 阈值 + 压缩比三样都要下发 |

判给下位机的 4 条（不在本包里，见 `Document/Update/hardware/v0.0.6/修复记录-界面问题单20261121.md` §4）：
旋钮 ADC 端点到不了 0/100（`0x2023`/`0x205A` 只读，上位机只显示）、Bootloader 的 USB Product String 与 VID、
噪声门「没有效果」的 DSP 侧确认。

## 5. 已知限制（重要）

1. **未签名**：目标机首次运行会弹 SmartScreen，点「更多信息 → 仍要运行」；被安全软件隔离需加信任。
2. **本机（开发机）Smart App Control / WDAC 开启**：未签名 exe 直接双击偶尔被静默拦（退出码 `0x80000003` 或干脆无反应），
   验证时用 `MIC STUDIO.exe` 启动器（自动补 `--no-sandbox`）或 `cmd /c start "" "<exe>" --no-sandbox`。
3. **噪声门听感**仍未闭环：上位机保证「开关 + 阈值 + 压缩比」三样都写进设备，DSP 是否真按这些参数工作要固件确认。
4. **旋钮两端**（最小不到 0 / 最大不到 100）是固件 ADC 映射，上位机不做补偿——加了就等于藏起设备真实值。
5. **DFU**：本版没有改刷写链路；真机侧 V0.0.6 的刷写成功率问题（`固件刷写失败记录-20261121.md`）仍按原结论处理，
   没有 SWD 退路时不要反复用 DFU 复测。
