## 3. 仍未闭合（非上位机代码可解）

1. **问题 1 的根因**在设备 ADC（同一档位回读差 1–3），上位机只能做显示去抖；要彻底稳定需固件滤波 / 多采样平均。
2. **问题 3 的根因**在固件写 Flash 时主循环停摆；上位机已把写帧密度从 ≈8 帧/s 降到「一次手势 1 帧 + 相邻写帧 ≥200 ms + 写超时后冷却 1 s」，但真正「设备卡死」的听感/灯效仍需按修复记录 §3 的顺序真机复测。
3. **问题 5 的听感**：`真机联调报告-第六轮.md` §7.1 发现固件预设初始化整体右移 2 字，若 DSP 按结构体取值，`0x205B` 起的 NoiseGate/3BandDrc 参数会落到错误字段，需要固件确认偏移。
4. **`pnpm run test:device` 的 T07 仍红**（19/20）：该用例跑在 `tools/vdevice/selftest.mjs` 自带的 `ParamClient` 上，其 TIMING 镜像还是旧的 `writeThrottleMs: 120` 固定窗口（`selftest.mjs:88`），与产品的尾沿 300 ms 语义不一致，所以 120 次写仍算出 24 帧。**这是自检脚本没跟上产品语义，不是上位机回归**；修复记录 §7.3 已列过这条遗留。建议把该镜像同步成 300 ms + 尾沿触发，`test:device` 即可回到全绿。
