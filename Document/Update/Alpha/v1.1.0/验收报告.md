**取证纪律（本轮实际踩过）**：
1. `vite` 的弃用警告写 stderr，PowerShell 会当错误 → 判定成败必须取 `$LASTEXITCODE`。
2. 两个 Agent 同时跑 `pnpm run test:device` 会争 8765/8766，表现为 `POST /control/reset 失败: fetch failed`（实测出现 14/20、13/20，复跑即 20/20）→ **验收必须串行占端口**。
3. `electron.exe` 是 GUI 子系统，`&` 不等待 → 用 `Start-Process -Wait`；stdout 接管会触发 EPIPE（已在开发期修复，见 D11）。
