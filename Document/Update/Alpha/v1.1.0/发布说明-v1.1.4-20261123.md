## 2. 怎么用（给客户）

1. 把 `MicStudio-1.1.4-portable.exe` 拷到目标机（Windows 10/11 x64），**双击即可**，不需要安装任何东西。
2. 若双击一闪而过（本机策略限制 Chromium 沙箱），改用同目录的 **`MIC STUDIO.exe`**（一键启动器）或
   `cmd /c start "" "<exe 完整路径>" --no-sandbox`。
3. 插着 M001（`VID 0A67 / PID 0010`）时启动后自动连接、自动同步参数，顶栏显示「已连接 / 已同步」。
4. 配置与启动日志在 **exe 同级的 `MicStudioData\`**（便携模式，不写系统 AppData）；出问题先看 `MicStudioData\startup.log`。
5. 没有真机时界面显示「演示数据」，可直接看交互；虚拟桥接通道需要另起 `pnpm run vdevice`，不随包分发。

## 3. 相对 1.1.3 的变化（全部在上位机界面层，不改协议与参数表）

| # | 问题单条目 | 本版行为 |
|---|---|---|
| 1 | 开关靠近左边文字、调参时不跳 | 三行阈值的开关紧跟标题文字，读数靠右；改阈值前后开关位置 0 位移（探针实测 `left 417.8 → 417.8`） |
| 2/3 | 均衡器默认频率 / 3–7 段频点 | 默认与「复位」后的频点变成 **50 / 20000 / 63 / 250 / 1000 / 4000 / 12500**；增益仍全 0、Q 全 0.7，类型不变 |
| 5 | 灯效调节放主页 | 「快捷开关」卡两列：`环境降噪 + 档位` / **`灯效 + 模式 0–7`**，与高级参数里的灯效是同一组寄存器，任改一处两边同步 |
| 6 | 三分频动态默认先关闭 | 上位机默认值、五个场景、「复位全部参数」全部按 **关** 下发；设备上电加载的那份预设仍是固件按参数表的值，需固件改（见 §5） |
| 7 | 会议模式改游戏模式 | 场景条：安静房间 → **游戏** → 播客 → 唱歌 → 自定义；处理链数值不变 |
| 8 | 软件打开默认自定义模式 | 启动即高亮「自定义」音色 + 自定义场景，曲线可直接拖；上次拖的曲线会记住（`micstudio.customEq`） |
| 9 | 五个场景都能单独调、自动保存 + 复位 | 选中场景后改任何参数/曲线都自动记到该场景名下；场景条右侧新增「复位」，一键清回该场景的出厂预设（只影响当前场景） |
| 11 | 增加最重负载测试 | 新增 `scripts/probes/heavyload-20261122.mjs`：开环境降噪 + 全部效果器 + USB 录音放音 + 持续调参 180 s，实测 0 超时 / 0 重试 / 0 CRC 错 |

判给下位机的 3 条（不在本包里，详见 `Document/Update/hardware/v0.0.6/修复记录-界面问题单20261122.md` §4）：

- **灯效数据没有上报**：上位机读写 `0x2072`/`0x2073` 的路径是通的（写入后能读回），灯有没有亮取决于固件是否真驱动灯。
- **耳机音量两端到不了 0 / 100**：`0x2023`/`0x205A` 是只读回读值（本轮真机 44 / 87），要固件校准 ADC 端点。
- **三分频动态默认关闭**：上位机已按 0 下发；设备上电预设是固件按参数表 G 列（=1）加载的，建议改表或改固件初始化。

## 4. 稳定性改进（验证中发现）

- **「复位全部参数」分批写**：真机（V0.0.6）在一次写回几十项参数 + 7 段 EQ 之后会 HID 无应答、只能拔插（旧版也能复现）。
  现在改成 6 项一批、批间隔 320 ms、EQ 一段一次，设备一进 error 立刻停手，按钮期间显示「正在复位…」。
- **自动连接冷启动重试**：设备自己复位（USB 上表现为拔插）回来后，先给两次 2 s 的冷启动重试再判定"停在升级模式"，
  不再一次同步失败就停手；同时订阅链路状态，用户手动连上的设备也算"曾经可用"。
- **一屏工作台纵向护栏**：1266×783 下不再出滚动条；窗口压到 700 高以下时中栏第一张卡内部滚动，
  不会让「输入开关」压到「快捷开关」（旧版在 1086×663 有重叠）。

## 6. 已知限制

1. **「复位全部参数」曾经把真机压成无应答**（V0.0.6，旧构建同样复现）：本版已改成分批写，
   拔插后连续复位 + 两轮 180 s 负载都不再复现；但根因在固件（一次写多字 + 落 Flash 的路径），
   固件修好之前仍建议避免在设备"很忙"时连续复位。详见修复记录 §5。
2. 场景的自动保存存在**本机**（渲染进程 localStorage），换机器 / 换系统用户不跟随；要跟设备走需要固件支持按场景存预设。
3. 「自定义」曲线与场景覆盖值不进设备预设区：别的机器连上来看到的仍是设备里那份预设。
4. 1086×663 下历史遗留的英文/窄视口文案截断（v1.1.3 缺陷清单 UI-02/UI-03/UI-04）未处理，等产品定文案。
5. `registers.ts` 与参数表现有两处产品差异（`drc3.Enable` 默认、3–7 段频点）。若产品希望设备出厂也是这套值，
   需要硬件侧出新版参数表，届时把 `PRODUCT_PARAM_DEFAULTS` / `PRODUCT_BAND_FREQS` 并回参数表。
